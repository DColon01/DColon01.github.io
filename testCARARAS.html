Executive overview

One connected solution. Two automated workflows.

The solution automates sequential steps in the risk assessment reporting lifecycle. CARA prepares and validates structured data; RAS uses the CARA data to generate a standardized Word document.

Stage 01 · Data preparation

CARA: Extract, validate, and populate

An AI-powered Power Automate workflow uses AI Builder Text Recognition (OCR) to extract information from PDFs and images. Bounding box coordinates help identify relevant content for populating SharePoint-hosted Excel templates.

  • OCR-based extraction from source files
  • Dynamic content identification using bounding boxes
  • Excel template population and formatting with Office Scripts
  • Data validation, error handling, and notifications
  • Automated email distribution of completed reports
Stage 02 · Document generation

RAS: Transform data into a Word report

A second AI-powered Power Automate workflow extracts and transforms Risk Assessment Summary data, using the prepared CARA data as the input to produce a standardized Word document.

  • Uses CARA-prepared data in the downstream process
  • Transforms report information into a consistent structure
  • Automates Word document generation
  • Reduces repetitive manual document preparation
  • Frees staff to focus on analysis and decisions
Key design principle: CARA is the upstream data-preparation stage. RAS is the downstream document-generation stage. The value comes from connecting the two, rather than treating them as unrelated automations.
Implementation

How the workflow delivers value

Each stage addresses a different source of manual effort while contributing to a more consistent reporting process.

01 / CARA automation

Converts information held in PDFs and images into structured spreadsheet data suitable for the next workflow stage.

  • Input: PDFs and image-based documents
  • Intelligence: AI Builder OCR and bounding-box processing
  • Processing: Power Automate and Office Scripts
  • Output: Populated, formatted Excel template
  • Controls: Validation, exception handling, notifications
Reported result
Preparation time reduced from approximately 30 minutes to just a few minutes.

02 / RAS automation

Uses the prepared CARA information to streamline creation of a standardized Risk Assessment Summary Word document.

  • Input: CARA-prepared data and RAS information
  • Processing: Data extraction and transformation
  • Orchestration: Power Automate and AI-powered processing
  • Output: Standardized Word document
  • Outcome: Less manual formatting and document preparation
Reported result
Automates a process that previously required approximately 3–4 hours of manual work.
